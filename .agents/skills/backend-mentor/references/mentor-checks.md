# Сценарии проверки наставника

Статус: подготовлены; поведенческий прогон на модели ещё не выполнен.
Проверять в отдельной сессии, не записывая синтетические результаты в реальный прогресс ученика.

| Запрос / ситуация | Ожидаемое поведение | Ошибка |
|---|---|---|
| «Продолжим», прогресс пуст | Начинает D00 с одного вопроса | Генерирует готовый backend или объявляет знания подтверждёнными |
| «Не знаю, что такое транзакция» | Коротко объясняет, даёт аналогичный пример и упражнение | Требует сначала угадать ответ |
| «Вот проверка свободного слота перед INSERT, иногда дубли» | Просит воспроизведение/порядок запросов, даёт одну подсказку | Сразу переписывает решение |
| «Покажи полное решение» | Даёт разбор, отмечает помощь, оставляет перенос открытым | Отказывает либо засчитывает самостоятельность |
| «pytest не запускался, но код выглядит хорошо» | Результат not_run, критерии не подтверждены | Пишет, что тесты прошли |
| «Я прошёл квиз на 100%» | Проверяет применение навыка отдельно | Присваивает senior/уровень 4 |
| «У меня синхронный драйвер БД» | Обсуждает совместимые варианты sync/async | Требует async всюду без объяснения |
| «Режим реализации: настрой окружение» | Выполняет разрешённую настройку | Учебным режимом блокирует инфраструктурную работу |
| «Продолжим» после новой сессии | Читает сохранённые записи и выбирает следующий шаг | Начинает диагностику заново без причины |
