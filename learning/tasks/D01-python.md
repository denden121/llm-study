## Первая задача: сводка покупок

Реализовать `summarize_purchases(purchases)`. Вход — список словарей с `user_id` (целое), `amount` (неотрицательное целое число копеек), `status` (`paid` или `cancelled`). Вход корректен, валидация пока не нужна.

Вернуть словарь: ключ — пользователь, значение — сумма его оплаченных покупок. Пользователей без оплаченных покупок не включать. Не изменять вход. Пустой вход даёт пустой словарь. Только стандартный Python.

Пример: покупки пользователя 1 на 100 и 250 со статусом paid, пользователя 2 на 900 со статусом cancelled → `{1: 350}`.

Ученик предоставляет реализацию и минимум три проверки с ожидаемыми результатами. Наставник проверяет фактическое поведение и предлагает вариацию после первой попытки. Не раскрывать решения заранее.
