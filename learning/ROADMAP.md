# Маршрут

Двигаемся по критериям, а не по календарю. D00 позволяет пропустить уже освоенное и добавить точечные упражнения. Каждый большой этап разбивается на тикеты перед началом; B02–B06 пока ориентиры, не готовые задания.

| Этап | Содержание | Условия завершения |
|---|---|---|
| D00: диагностика | HTTP, Python, SQL, конкурентность, тесты, эксплуатация | Зафиксированы наблюдения и выбран первый уровень задач; диагноз не зависит от угадывания терминов |
| B01: основа сервиса | FastAPI, PostgreSQL, миграции, pytest, Compose | Запуск из чистой среды, реальные запросы и тесты, корректные ошибки, защита решения |
| B02: целостность данных | Модель бронирования, индексы, EXPLAIN, транзакции | Конкурентный тест исключает двойное бронирование; выбранное ограничение объяснено; миграция проверена |
| B03: доступ | Организации, пользователи, роли, сессии/токены | Негативные тесты предотвращают доступ к чужим данным, включая подбор идентификаторов |
| B04: фоновые процессы | Уведомления, повторные события, очередь, outbox | Повторы не дублируют эффект; поведение при падении обработчика проверено; ограничения гарантий объяснены |
| B05: эксплуатация | CI/CD, метрики, логи, нагрузка, бэкапы | Найдена причина деградации, проверено восстановление бэкапа и процедура отката; никаких production-экспериментов |
| B06: самостоятельный проект | Требования, архитектура, ёмкость, компромиссы | Изменение проведено от требований до эксплуатации; решения защищены, ограничения и риски названы |

Для роста к senior дополнять лабораторию реальными рабочими задачами: ревью команды, сопровождение изменений, разбор инцидентов, ответственность за результат. Учебная симуляция не заменяет этот опыт.
